# Panda Live Full Website

Ready for static deployment.

Files:
- index.html
- style.css
- app.js
- vercel.json

Important:
The included site uses demo/public placeholder cards. Replace `loadChannels()` in `app.js` with an API or data source you are authorized to use. It does not copy, bypass, or proxy protected streams.

Deploy:
1. Extract ZIP.
2. Upload the folder to your Git repository or deployment service.
3. Deploy as a static site.
